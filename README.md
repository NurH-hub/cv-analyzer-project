# CV Analyzer Project

AI-powered CV Analyzer web application built using React and Node.js.

## Features

- CV and Job Description analysis
- AI-powered suggestions
- PDF CV upload support
- Match score system
- Modern responsive UI
- Dark mode support

## Technologies Used

- React
- JavaScript
- Node.js
- Express
- Gemini AI API
- CSS

## How to Run

### Frontend

```bash
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
node server.js
```
